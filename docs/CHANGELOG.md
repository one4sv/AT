# История изменений AchieveTogether

Краткая хронология ориентиров разработки и крупных изменений. Даты ранних версий — даты соответствующих изменений или сведения от автора, а **не подтверждённые официальные даты выхода релизов**. Актуальное поведение описано в профильных документах и исходниках `main`.

## Основные этапы

| Дата | Версия / обновление |
| --- | --- |
| 14.07.2025 | `0.0 The Beginning` — начало проекта по сведениям автора. |
| 26.08.2025 | `0.1 The Foundation` — основа приложения и первый коммит. |
| 22.09.2025 | `0.2 Act` — календарь и активности. |
| 14.10.2025 | `0.3 Dialogue` — переписка и медиа. |
| 23.10.2025 | `0.4 Firework` — публикации и реакции. |
| 21.01.2026 | `0.4.7.2` — подтверждённая точка ранней истории. |
| 25.01.2026 | `0.5 Aphrodite` — версия и групповые беседы. |
| 31.10.2026 | `0.6 Affinity` — подтверждённая история разработки совместных активностей. |

## Обновления интерфейса и инфраструктуры

- **02.11.2026** — права и роли, приглашения в активности, новая структура roadmap, настройки и UI.
- **03–04.11.2026** — конфиденциальность, жесты контекстных меню, расписание, статистика, своя палитра и фоновые сцены; переход к `dev 0.6.2`.
- **05.11.2026** — модалки фонов, скорость движения, паттерны, каталог, поведение на телефоне, английские названия версий.
- **06.11.2026** — редактор Wallpaper Studio, предпросмотр и применение фонов, разделы Японии и Античности, проверка мобильных и desktop-ассетов.
- **07.11.2026** — обновление фотообоев, оптимизация загрузки/кэша, Web Push, новые правила гостевого интерфейса и документации.
- **08.11.2026** — исправления оформления ленивых страниц и активности; порядок слоёв хедера; легенда значков фоновых возможностей стала постоянной независимо от настроек. Выпуск `0.6.3 Songbird`.
- **11–12.11.2026** — разовые планы, напоминания о планах, новые настройки (часовой пояс, «При открытии приложения»), переработанная страница `/habit`; выпуск `0.6.4 Waypoint` 12.11.2026. Авторизованный E2E на двух аккаунтах и iPhone не подтверждены, см. [RELEASE_QA.md](RELEASE_QA.md).

Актуальные функции и невыполненное QA: [WALLPAPERS.md](WALLPAPERS.md), [COLLABORATION_AND_PERMISSIONS.md](COLLABORATION_AND_PERMISSIONS.md), [I18N.md](I18N.md), [RELEASE_QA.md](RELEASE_QA.md), [TESTING_AND_RELEASE_AUTOMATION.md](TESTING_AND_RELEASE_AUTOMATION.md). Не считать описание изменения доказательством production-деплоя либо визуального E2E.
