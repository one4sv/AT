# История изменений AchieveTogether

Краткая хронология ориентиров разработки и крупных изменений. Даты ранних версий — даты соответствующих изменений или сведения от автора, а **не подтверждённые официальные даты выхода релизов**. Актуальное поведение описано в профильных документах и исходниках `main`.

## Основные этапы

| Дата | Версия / обновление |
| --- | --- |
| 14.07.2025 | `0.0 The Beginning` — начало проекта по сведениям автора. |
| 26.08.2025 | `0.1 The Foundation` — основа приложения и первый коммит. |
| 22.09.2025 | `0.2 Act` — календарь и активности. |
| 14.10.2025 | `0.3 Dialogue` — переписка и медиа. |
| 23.10.2025 | `0.4 Firework` — публикации и реакции. |
| 21.01.2026 | `0.4.7.2` — подтверждённая точка ранней истории. |
| 25.01.2026 | `0.5 Aphrodite` — версия и групповые беседы. |
| 31.10.2026 | `0.6 Affinity` — подтверждённая история разработки совместных активностей. |

## Обновления интерфейса и инфраструктуры

- **22.11.2026** — `.smHeader::before` больше не выступает на `1.8dvh` ниже заголовка: `inset:0`, сохраняется размытие `2px` и равный отступ списков.

- **22.11.2026** — выровнено расстояние от smHeader до обычного списка и списка поиска: видимое начало обоих 5dvh; обычный margin-top 4→5dvh, поисковый 5.5→4.5dvh с сохранённым padding-top .5dvh. Добавлен regression-тест, нижняя прокрутка и жесты без изменений.

- **22.11.2026** — поиск настроек из SideMenu открывает нужную секцию и передаёт `settingId` для штатных прокрутки и подсветки, общая функция маршрутизации с `/settings`. Удалена маска, скрывавшая элементы под `smHeader`; оставлен настоящий `backdrop-filter:blur(2px)` с более прозрачной 25% подложкой.

- **22.11.2026** — blur подложки `smHeader` ослаблен с 6 до 2px (WebKit включён), другие свойства и паддинги не менялись.

- **22.11.2026** — контент SM перестал просвечивать в заголовке при прокрутке благодаря закреплённой на `.ListWrapper` маске `0..4.5..6.2dvh` (включая WebKit), слабое размытие 6px сохранено. Дополнительный нижний отступ поиска увеличен с 2dvh до 5dvh, не затрагивая `--sm-nav-clearance` и safe-area.

- **22.11.2026** — размытие `smHeader` ослаблено с 24px до 6px (saturate 1.7 → 1.15), дополнительный нижний отступ поиска SMlist сокращён с 9dvh до 2dvh при сохранённом nav clearance и safe-area.

- **22.11.2026** — поиск SM: контакты/пользователи/сообщения, собственные активности/планы перед чужими, настройки и публикации с приоритетом автора; пустой запрос не показывает чужие активности/сообщения/посты. Постам добавлен разрешённый аватар автора, SVG подложки `--mc`, карточкам 24px radius, дополнительный нижний scroll. Хедер полностью размывает фон, выпадающее меню центрируется по выбранной кнопке с ограничением по ширине SM в любом режиме. Browser/iPhone QA открыт.

- **22.11.2026** — фильтр поиска SM вынесен из ввода в отдельный state; результаты сразу загружаются без текста с server-side ACL и skeleton, «Пользователи» перенесены в «Чаты», показаны аватары/иконки тегов, улучшено пустое состояние, добавлены SVG пунктов фильтра в верхнем и нижнем меню. Верхнее меню обычной ширины, нижнее шириной 94%. Серверные `/ms` и `/new` поддерживают пустой поисковый текст. Реальные браузеры и мобильный QA — отдельно.

- **22.11.2026** — поиск SideMenu перенесён из отдельного всплывающего `smGlobalSearch` в `.SMlist`, фильтры распределены по разделам, добавлены slash-подсказки и синхронизация `SMnav`/`SMheader`, опция «Без фильтров». Уточнены общий список `@` в чате и отступы пользовательских карточек. CI и мобильный E2E учитываются отдельно.

- **22.11.2026** — тег «Здоровье» (`FirstAidIcon`) в группе health и серверном whitelist планов; уменьшен левый padding `chatUserPick`; slash-команды подсвечиваются фоном `accent_highlight`; в «Избранном» доступны `/habit`, `/plan` (поделиться), `/post`, `/user` наряду с созданием `/act`/`/plan`, без `/invite`/`/group`.

- **22.11.2026** — `/invite` в групповой беседе теперь привязывает выбранную активность или план к текущему чату через штатные API и подтверждение; для плана приглашения участникам отправляются индивидуально. В личном чате остаётся прямое приглашение собеседнику. Добавлен фильтр собственных непривязанных объектов и защита от переноса активности в чужую беседу.

- **22.11.2026** — у sharedEntityCard уменьшен левый отступ, добавлен skeleton загрузки, автор пересланного поста стал ссылкой; увеличен предпросмотр текста поста. В обычных постах кнопка пересылки рядом с комментариями использует существующее контекстное действие. Скелетоны медиа распространены на вложения публикаций и видео чата.

- **22.11.2026** — карточки отправленных пользователей, активностей, планов, постов и бесед без текстовой подписи отображаются без внешнего пузыря, с прозрачной строкой статуса; реальные теги и локализованные сведения, предпросмотр поста. Slash-команды показывают доступные объекты сразу, приглашения подтверждаются в текущем личном чате, внешний @ отправляет карточку без push; SideMenu показывает тип последней сущности.

- **22.11.2026** — у карточки перед отправкой подпись «Пользователь / Активность / План / Публикация / Беседа» вместо общего заголовка, исправлены отступы и выход текста; одиночные фотографии без подписи подстраиваются под ширину изображения и не имеют фона пузыря.

- **22.11.2026** — начаты этапы 4–6 общего механизма объектов AT: автодополнение `@nick`, защищённые типизированные карточки пользователей/активностей/планов/постов/бесед, `/invite` через существующий picker, универсальный поиск SM с фильтрами и раздельные уведомления бесед/упоминаний. `/group` переходит в существующий защищённый интерфейс приглашений группы; полный E2E остаётся в работе.

- **22.11.2026** — в «Избранном» распознаются планы вида `Психотерапевт 30.11 16.00` (название перед датой); выровнены вертикальные отступы и минимальные высоты textarea в чате, комментариях, профиле, описании беседы и других формах.

- **22.11.2026** — исправлена генерация `accent_highlight` / `grad_highlight` для короткого HEX белого и чёрного: теперь используются корректные RGBA; добавлена различимая подсветка для монохромных и почти нейтральных пользовательских акцентов в светлой/тёмной темах.

- **22.11.2026** — для поля «Периодичность» в `/act` добавлены четыре локализованных автоподсказки с пояснениями, поддержкой стрелок и Enter. Выбор не закрывает командный редактор; поля недельного и циклического режима сохраняются.

- **22.11.2026** — в `/act` и `/plan` убраны цветные фоны названий полей и имени команды; `--accent_highlight` остаётся только вокруг вводимых значений, отступы подстроены для ПК и мобильного.

- **22.11.2026** — в редакторе `/act`/`/plan` увеличены padding и промежутки; заголовки полей и набираемые значения выделяются фоном `--accent_highlight`, активный `textarea` больше не подчёркивается.

- **22.11.2026** — редактор `/act` и `/plan` вместо полноширинных полей переведён на компактные inline `textarea` с авторасширением от 1px, акцентными названиями и сохранёнными переходами Enter/Backspace. Дата и время принимают текстовые форматы с проверкой; добавлены RU/EN переводы `startShort`/`endShort`, крестик перенесён к правому краю.

- **22.11.2026** — список slash-команд в «Избранном» больше не закрывается при нажатии на TA: внутренний обработчик outside-pointerdown исключает `.chatCommandEditor`; остальные способы закрытия сохранены.

- **22.11.2026** — выпадающий список `/` в «Избранном» растянут на всю ширину строки ввода чата (включая область кнопок), вместо ширины TA; снят лимит 32rem только у списка команд. `--mc`, blur 6px и адаптация viewport сохранены.

- **22.11.2026** — в AddPlan выбор тега из портального списка больше не закрывает Blackout; повторный клик по подсказке последнего сообщения «Избранного» снова открывает форму с заполненными полями. Сохранены фокус после кнопки `/` и активация команды по пробелу.

- **22.11.2026** — исправлены slash-команды в «Избранном» после проверки на iPhone: отдельный portal для blur 6px, закрытие повторным нажатием / и нажатием вне, компактная мобильная сетка редактора, сохранение фокуса TA и автоматическая активация /act или /plan по пробелу. Тесты парсера дополнены.

- **22.11.2026** — `/act` и `/plan` в «Избранном» переведены со всплывающих модалок на встроенные поля внутри TA. Enter/Backspace переключают поля; после последнего Enter API создаёт объект и отправляет сообщение «План создан»/«Активность создана» с карточкой в стиле приглашения. Список команд использует `--mc` и blur 6px, placeholder сокращён. Сервер активности теперь возвращает `habit_id`.

- **21.11.2026** — «Избранное»: локальный парсер расписания и дат последнего сообщения, кликабельная подсветка `accent_highlight`, открытие стандартных модалок с заполненными полями, отсев прошедших планов, переключатель в ChatsTab и RU/EN. Тесты добавлены в CI.
