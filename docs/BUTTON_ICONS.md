# SVG и иконки в кнопках AT

Эти правила относятся к функциональным кнопкам, а не к иллюстрациям [SectionArt](SVG_ART.md).

## Размер и геометрия

- Использовать существующие Phosphor/Lucide иконки и классы кнопок, не заменять их картинками или самодельным SVG без причины.
- В кнопке только с иконкой (редактирование, удаление, закрытие) базовый визуальный размер SVG **24 × 24 px** при кнопке 42–44 px. Для компактных существующих действий допустимо 20px; размер конкретного штатного компонента сохранять. На телефоне цель нажатия не меньше 44px там, где позволяет существующая геометрия.
- `size={24}` задаёт атрибуты SVG, но общие CSS могут их переопределить. Проверять вычисленный размер в DevTools. В кнопках с заданной геометрией задавать непосредственному `button > svg` width/height и min-width/min-height одинакового размера, `flex-shrink:0` либо `flex:0 0 24px`. Центрировать flex/grid, при фиксированной квадратной кнопке не оставлять большой горизонтальный padding. Не масштабировать через transform и не увеличивать саму кнопку вместо SVG.
- Не применять широкое правило ко всем SVG: стрелки SelectList, индикаторы, иллюстрации и мелкие статусные значки имеют свою геометрию. Проверять селектор, порядок импорта и mobile media.

## Цвет и доступность

- Цвет обычных иконок через текущие токены, опасное действие — `--notValid`, градиентное подтверждение — `--inner_text` и border:none. SVG наследует currentColor.
- Действие только с SVG требует `aria-label`; кнопки в форме — type="button", если это не submit.
- Проверять реальную иконку на desktop и iPhone, её размер, центровку, отсутствие shrink и влияние на соседние поля. Не считать атрибут size доказательством визуальной проверки.

Пример: `.goalIconButton` и `.goalStageRemove` в `src/components/modules/scss/goalWorkspace.scss`.
