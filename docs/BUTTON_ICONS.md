# SVG в кнопках AchieveTogether

## Размеры и геометрия

- Для стандартной круглой кнопки действия 42–44 px использовать SVG 24 × 24 px; маленькие иконки 16–20 px оставлять только в компактных строках и меню с текстом. Не уменьшать иконку редактирования/удаления до декоративной точки.
- Центрировать SVG по обеим осям через flex/grid; у icon-only кнопки убрать лишний padding. Явно задать width/height и flex-shrink: 0 локальному прямому потомку > svg, если общий SCSS переопределяет size библиотеки.
- Не менять размер самой кнопки или расположение соседних элементов без требования; одинаковые действия в одной группе имеют равный размер. Проверить computed styles, а не только size={24} в JSX.
- Использовать существующие Phosphor/Lucide иконки, currentColor, наследование цвета темы. Опасное действие — --notValid; градиентные кнопки — --inner_text и без border.
- Для кнопки без текста обязателен aria-label RU/EN. На телефоне сохранять удобную область нажатия и центрирование.
- Не вводить глобальное правило для всех svg: логотипы, иллюстрации, стрелки SelectList и индикаторы имеют собственную геометрию.

## Цели

В `goalWorkspace.scss` у `.goalIconButton` прямые SVG 24 × 24 px, padding 0; у `.goalStageRemove` такой же размер SVG, высота кнопки равна соседним полям. Проверять редактирование, удаление, привязки, этапы и обе темы.
