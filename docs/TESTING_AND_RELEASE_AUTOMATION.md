# Проверки клиента

Workflow `.github/workflows/client-ci.yml` запускается на push в main, pull request и вручную. Используется Node 22.

| Проверка | Назначение |
| --- | --- |
| `npm run check:release` | Сверяет текущую версию пакета, roadmap, About и трёх MD, уникальность версий, английские названия и ключи пяти пар словарей RU/EN. |
| `npm run check:lazy-styles` | Проверяет подключение стилей ленивых экранов и модалок. |
| Тесты в `tests/` | Проверяют отдельные правила UI и данных, включая хронологию планов, команды, упоминания, поиск, композиции и Service Worker. Точные команды для TypeScript и JS перечислены в workflow. |
| `npm run build`, затем `npm run check:bundle` | Подготовка обоев, проверка TypeScript, сборка Vite, контроль размера начального JavaScript. |

## Браузерные сценарии

Установить зависимости в `tests/e2e` и браузеры Playwright, запустить `npm run dev`. Команда `npm run test --prefix tests/e2e` использует конфигурацию проекта. CI запускает публичный smoke и проверки настроек в Chromium, а настройки также в Firefox и мобильном WebKit. Авторизованные сценарии используют тестовый аккаунт и локальный `AT_E2E_STORAGE_STATE`. Результаты публичных тестов, ручной проверки на физическом iPhone и проверки с двумя аккаунтами фиксировать отдельно в [приёмке выпуска](RELEASE_QA.md).
