# Обратная связь и жалобы AT

Общая форма реализована ленивой Blackout-модалкой `src/components/modules/FeedbackModal.tsx`. Кнопка доступна внизу `/info` в виде `settingButt` с собственной темой `SectionArt theme="feedback"`, а также в блоке поддержки `/info/contacts`. Стили находятся в `FeedbackModal.scss` и Info SCSS. Локали — `common.feedback` и `info.info.feedback` / `info.contacts.feedbackOpen` (RU/EN).

## Сценарии

- Обычная форма предлагает `RadioGroup` типа обращения: ошибка, предложение, жалоба, другое. Для общей жалобы показывается дополнительная группа выбора причины, но не требуется связанный объект. При отсутствии авторизации можно указать email для ответа.
- Контекстные меню **чужих** аккаунтов, постов, сообщений, комментариев и активностей содержат «Подать жалобу». Открывается та же модалка с `blackout.feedback` (targetType/targetId/targetUrl); заголовок фиксирован, **выбор типа обращения скрыт**, выбор причины через `RadioGroup` обязателен. Отправить жалобу на контент может только вошедший пользователь.
- Использовать существующие `Blackout`, `RadioGroup`, `TA`, `SectionArt`. Не создавать отдельную модалку/радиокнопки или независимый SVG, не добавлять font-weight.

## Сервер и письмо

`POST /api/feedback` проксируется на `routes/system/feedback.js` в `one4sv/achievetogether-server`. Сервер использует `authenticateUser`, проверяет Origin, тип, причину, длину текста, ID объекта и ограничение частоты. Обращение передаётся через общий `services/sendmail.js` на `SUPPORT_EMAIL` (резерв — `kutenko18@gmail.com`). HTML-письмо оформлено в тёмной палитре AT, включает номер обращения, тему, тип, причину, автора, путь/ID и описание; каждое пользовательское поле HTML-экранируется.

**Личные сообщения, файлы и их содержимое не пересылаются автоматически** — модератор получает только ID и путь и должен проверить доступ своими полномочиями. В текущей реализации форма не прикрепляет изображения и видео. Отдельные модераторская очередь и защищённые вложения — возможное развитие, не считать реализованными.

## Проверка

- Публичный Playwright: карточка Info, контакты, открытие модалки, RadioGroup и закрытие без отправки. Реальную отправку писем из браузерного smoke не запускать.
- Сервер: `npm test`, проверка HTML-экранирования и безопасного пути.
- Перед объявлением Done вручную пройти отправку в настоящую почту, 429, ошибки почтового провайдера, гость/участник/владелец, жалобы из пяти контекстов, iPhone Safari, RU/EN. **Успешная сборка Vercel или GitHub CI не равна проверке отправки через Render.**
