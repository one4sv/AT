# Каталог настроек AT

Единый каталог поиска: `src/pages/Settings/Arrays/searchableSettings.ts` (`useSearchableSettings`). Идентификаторы совпадают с `data-setting-id` в компонентах настроек. `settingsSearchNavigation.ts` определяет путь и состояние перехода. `SettingCatalogIcon` использует icon, icon2, icon_color, icon2_color или icon_text из каталога; применяется в поиске /settings (включая недавние и популярные), глобальном поиске SideMenu, карточках пресетов и ссылок на настройки в чате. Для уже отправленной карточки каталог включает пункты других платформ, но поиск оставляет только доступные на текущем устройстве. Цвета и текстовые значки могут зависеть от текущего оформления/значения.

## Разделы

| Раздел (route) | Пункты каталога |
| --- | --- |
| Аккаунт (acc) | Редактирование профиля, email, удаление аккаунта |
| Основные (gen) | Стартовая страница, поведение свайпа и запуска SideMenu (мобильные), предпросмотр композиций, подсветка краёв, автозагрузка изображений, GIF, кэш, размер текста, форматы даты/времени, часовой пояс, быстрые действия, язык |
| Интерфейс (pers) | Нативный стиль (при доступности), тема, акцент, градиент, собственные цвета, оформление, размытие оформления, обои, размытие/движение/скорость/фильтры фона, композиции, расположение SideMenu (ПК) |
| Активности (activities) | Архив в SideMenu и профиле, цели, дневная сводка, начало недели |
| Чаты (chats) | Реакция, двойное нажатие, статус набора, Enter для отправки, умные подсказки Избранного, приветственное сообщение |
| Уведомления (notes) | Общие, сообщения, упоминания, разрешения браузера, напоминания активностей, общее время, индивидуальные правила, напоминания планов |
| Приватность (privacy) | Видимость профиля, активностей, постов и планов; приглашения в активности, планы и беседы (контакты и остальные) |
| Безопасность (security) | 2FA, пароль, устройства, предпросмотр ссылок, cookies |

## Команды и границы

`/set` открывает/изменяет настройки только в Избранном. `/settings` отправляет ссылку/карточку во всех чатах. Оба используют каталог через `settingCommands.ts`; допустимые значения пресетов отдельно валидирует `sharedSettings.ts`. Наличие пункта в поиске не означает возможность менять его значение командой: аккаунт, приватность, серверные и сложные настройки остаются в штатных формах. Исключения приватности доступны только внутри соответствующих правил; они не регистрируются в каталоге, не появляются в поиске /settings, SideMenu и подсказках /set, /settings. Кнопки внутри форм (сохранение, удаление исключения, отдельный цвет, редактирование правила), варианты выбора и модальные поднастройки не являются самостоятельными пунктами каталога. Подробности: [безопасность и хранение](SETTINGS_ACCOUNT_SECURITY.md), [композиции](COMPOSITIONS.md), [обои](WALLPAPERS.md), [команды](CHAT_COMMANDS.md).

При добавлении настройки: зарегистрировать section/id, RU/EN название, категорию и SVG/текст; поставить уникальный data-setting-id на соответствующий элемент; проверить переход из обоих поисков и команд. Для безопасного пресета дополнительно определить допустимые значения и действие применения. Не дублировать иконки по типам результата.
