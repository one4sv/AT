## Принципы

1. Сначала найти уже существующий компонент/миксин/хук, не создавать копию.
2. В новом интерфейсе **не добавлять `font-weight`**, сохранять стиль автора, использовать 24px и `vw/dvh` по месту.
3. Каждый новый текст переводить в RU и EN, если он входит в локализуемый UI. О непереведённых частях сообщать как о техдолге.
4. SVG разделов рисовать внутри общей системы `SectionArt`, а не создавать вторую несовместимую оболочку.
5. Права проверять на сервере. Разрешения в React не обеспечивают защиту.
6. Не выдавать статус деплоя за E2E-проверку.
