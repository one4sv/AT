# Рисованные SVG в AT: SectionArt и единый стиль

Речь о **декоративных иллюстрациях** для Info и Settings, а не обо всех иконках приложения. Каноническая реализация — `src/components/ts/SectionArt.tsx` и `src/scss/SectionArt.scss`. Пример отдельного сюжета в общей системе: `src/pages/Info/RoadmapArt.tsx`, который рендерит `<SectionArt theme="roadmap" mini/>`.

## Устройство системы

- `SectionArt` принимает `theme?: ArtTheme`, `section?: string` и `mini?: boolean`. `section` преобразуется через объект `themes` в `SectionArt.tsx`; не каждый ключ маршрута равен имени темы.
- Внутренний `Motif` выбирает уникальную рисованную композицию по `theme`. Оболочка `SectionArt` общая: `viewBox="0 0 360 176"`, мягкие эллипсы, дорожки, частицы, боковые элементы и градиент.
- Текущие темы (сверять с `ArtTheme`): `general`, `account`, `personalization`, `habits`, `chats`, `notifications`, `security`, `privacy`, `about`, `contacts`, `faq`, `policy`, `terms`, `growth`, `future`, `community`, `roadmap`, `feedback`.
- Идентификаторы градиента и clipPath создаются через `useId`, поэтому иллюстрации не конфликтуют, когда находятся на странице несколько раз.
- `IntersectionObserver` ставит `isVisible`: анимации невидимых иллюстраций приостанавливаются. Если добавлять анимацию, соблюдать это поведение.
- `aria-hidden="true"`, `focusable="false"`, `pointer-events: none`: рисунок декоративный, не подменяет текстовую информацию и не блокирует нажатия на карточку.

## Визуальные элементы и цвета

Использовать **общие классы**: `artPaper` — карточка; `artTint` — акцентная полупрозрачная фигура; `artSolid` — заливка градиентом; `artLine` — линии; `artInverse` — светлый рисунок на акцентной заливке; `artTrail` — пунктир; `artRing` — окружность; `artWash` / `artShadow` — глубина. Цвета из темы: `--mc`, `--accent`, `--accent_op`, `--accent_text`, `--grad`, `--inner_text`, `--borderHabit`.

Используемый в SVG `--art-paint` вычисляется из `<linearGradient>` на `--accent` и `--grad`. **Не задавать фиксированные оранжевые/фиолетовые цвета**, так как пользователи меняют акцент и фон. Не добавлять собственный прямоугольник-плашку с другим радиусом вокруг сюжета: оболочка уже обеспечивает единое визуальное оформление.

Анимационные классы: `artBob`, `artPulse`, `artShimmer`, `artSway`, `artOrbit`, `artSlide`, `artDraw`, `artBars`; смещения `artDelay1`/`artDelay2`. Новые эффекты — только если существующих недостаточно. В SCSS есть `@media (prefers-reduced-motion: reduce)`: выключать движение для пользователей с уменьшенной анимацией.

## Размеры и размещение

- Полная иллюстрация: `<SectionArt theme="faq"/>` — перед текстом раздела `infoText`/`settingTab`. В соответствующей оболочке сверху применяется единый широкий баннер (`12vh`).
- Миниатюра в кнопке: `<SectionArt section={s.tab} mini/>`. Контейнер `.settingButt:has(> .sectionArt--mini)` использует grid с правой колонкой `8vw` на ПК и `20vw` на мобильном.
- Для roadmap только **содержание рисунка** уникально: `RoadmapArt` передаёт `theme="roadmap"`. Для Info рядом с другими карточками нельзя делать вторую отдельную систему CSS.
- При добавлении рисунка к новому Info-разделу проверить `section` → `themes` либо явно задать `theme`. Если новая тема не зарегистрирована, отображается `general`.
- Все рисунки должны помещаться в clipPath, не выступать за кнопку/край экрана, не накрывать тексты и не обрезать смысловые элементы.
- Псевдокласс `:has` применяется только там, где это уже предусмотрено стилями; учитывать мобильные правила и размеры миниатюр.

## Как добавить новый рисунок

1. Найти существующий вариант в `Motif`, который можно использовать без нового сюжета. Если задача требует уникальный рисунок, добавить значение в `ArtTheme`.
2. В `switch (theme)` добавить отдельный `case` и формы (`rect`, `path`, `circle`, `g`) **в локальных координатах около (0,0)**: общая оболочка уже выполняет `translate(180 87)`.
3. Применить `artPaper`, `artTint`, `artSolid`, `artLine` и существующие анимационные классы. Не рисовать новый фон целой кнопки и не создавать вторую общую сетку.
4. Вставить `<SectionArt theme="new-theme" mini/>` в кнопку Info/Settings; если удобно, разрешён тонкий wrapper, как `RoadmapArt`.
5. Проверить миниатюру в одном ряду со старыми: одинаковая масштабность, толщина линий, тени, частицы, контраст и динамика.
6. Проверить `default` и `glass`, светлую/тёмную тему, произвольный accent/grad, ПК и узкий экран, `prefers-reduced-motion`.
7. Обновить этот документ и [CUSTOM_COMPONENTS.md](CUSTOM_COMPONENTS.md), если появился новый общий контракт/тема.

```tsx
// Для нового сюжета изменить ArtTheme и Motif в SectionArt.tsx.
<SectionArt theme="roadmap" mini/>
```

## Чем не является SectionArt

- Иконки элементов управления обычно берутся из `@phosphor-icons/react`; не заменять их большими иллюстрациями.
- Пользовательские аватарки, фотографии публикаций и QR-коды не являются декорациями SectionArt.
- Для предпросмотра изображений есть `ImgPrev` и `useImagePreview`; для QR — `ShareAcc`. Эти компоненты решают иные задачи.
