- Частичная локализация RU/EN через i18next, namespaces `common/sign/info/settings/acc`. Не объявлять локализованными все остальные экраны.
- Документация dev 0.6.1, совместных активностей, SCSS, SVG и QA выделена по профильным файлам — [индекс](README.md).

## Ключевые инварианты продукта

1. У активности без беседы — владелец и максимум один приглашённый/принятый участник; для большего числа нужна беседа.
2. `completion_mode` определяет общие/личные отметки дня; `metric_progress_mode` — общие/личные метрики; `schedule_blocks_mode` — блоки расписания. Это **разные** настройки.
3. Беседа определяет права и разрешения участника; заблокированный не должен получать доступ через альтернативный API.
4. `owner` (владелец беседы) всегда имеет 15/15 прав, приоритет 100, роль нельзя изменить, назначить по умолчанию или вручную выдать другому пользователю.
5. Нельзя выполнить дату до вступления в беседу, включая обход через API. День вступления допустим; сравнение по календарю Москвы.
6. Во всех модалках применять общий `Blackout`, в выборе ролей — `SelectList`, текстовые поля — `TA`/`AutoDesc`. Не добавлять лишний крестик/«Отмена» в модалку «Права и роли».
7. Пользовательский стиль: 24px, `vw/dvh`, тема, многострочный SCSS, **не добавлять `font-weight`**.
8. Русская и английская локализации меняются синхронно; уникальные рисованные SVG создаются в `SectionArt`.

## Открытые проверки, НЕ выдавать за завершённые

- Полное E2E совместной активности в **беседе**: приглашения, роли, запреты, личное/общее выполнение, календарь, статистика, таймер, счётчик, задачи, расписание, комментарии и realtime. Linear [ONE4SV-49](https://linear.app/atone4sv/issue/ONE4SV-49).
- Прямые API-попытки редактирования `owner` и обхода даты вступления. Проверять выход/повторное вступление и смену `joined_at`.
- iPhone Safari: редактор постов, вставка изображений, сохранение существующего поста, поля ввода, модалки, скролл, жесты `GroupInfo`.
- Отложенная синхронизация публичного roadmap с Linear; существующая страница сейчас использует локальный `roadmapData.ts`. Linear [ONE4SV-50](https://linear.app/atone4sv/issue/ONE4SV-50).
- Проверка полноты переводов за пределами Info/Sign/Settings/Acc и доступности всех рисунков/кнопок.

Не описывать эти сценарии как уже сломанные: это **неподтверждённые или открытые регрессии**, требующие воспроизведения. Подробная матрица — [RELEASE_QA.md](RELEASE_QA.md).

## Сервисы и порядок работы

Клиент [one4sv/AT](https://github.com/one4sv/AT), [Vercel](https://achievetogether.vercel.app/). Сервер [one4sv/achievetogether-server](https://github.com/one4sv/achievetogether-server), [Render](https://achievetogether-server.onrender.com/); база — Supabase. Изменения в `main` запускают автодеплой; отдельный ручной деплой без необходимости не нужен.

Тестовые данные не удалять и не изменять ради проверки. Сначала изучать `habit_members`, `chat_members`, SQL RPC и миграции. Не коммитить пароли/токены. После коммита сверять опубликованный SHA, затем поведение.

## Исторические указания, которые остаются полезными

- Приглашения в активности появляются в личном чате, принятый участник должен получить доступ, отказ и повторное приглашение — отдельные сценарии.
- Меню совместной активности отображает владельца и пару либо беседу; в беседе прямое приглашение третьего в активность не предлагается.
- Подтверждение требуется для исключения и удаления; обрабатывать права, приватность приглашений, блокировки и комментарии с авторами.
- Жесты SideMenu, горизонтального слайдера и сворачивания не могут выполняться одновременно.
- Реальный пользовательский пример привычки №19 **не использовать** для автоматизированного изменения данных.

Детали см. в [COLLABORATION_AND_PERMISSIONS.md](COLLABORATION_AND_PERMISSIONS.md), [habit-invitations.md](habit-invitations.md) и [V0_6_FEATURES_AND_QA.md](V0_6_FEATURES_AND_QA.md).

### dev 0.6.2 — статистика, палитры и интерактивные фоны

- **Schedule**: контейнер с фиксируемой полезной высотой `42dvh` (мобильный `48dvh`), `min-height:0` у flex-скроллеров дней и вложенная вертикальная прокрутка, чтобы блоки не обрезались в строку высотой несколько сантиметров. При архивном просмотре расписание остаётся видимым без возможности редактирования.
- **Статистика**: `OverallStats` — адаптивный dashboard: кольцо выполнения, ключевые числа, карточки стриков/перерывов, детальный график и счетчик/таймер только для подходящего типа активности. Внутри `mc` карточки используют `interact` без декоративного border, кроме внешнего слоя с фоном сайта. Не использовать `font-weight` в новых SCSS.
- **Собственные цвета**: одна кнопка «Свои цвета» под обоими пикерами открывает общую модалку `CustomThemeColor` с двумя `input[type=color]`, двумя HEX-полями, предпросмотром градиента и единым сохранением. Значения хранятся в `localStorage` (`customAccentHex` / `customGradHex`) и включаются значениями темы `accent="custom"` / `grad="custom"`. `applyCustomPalette` применяет `--accent`, `--accent_text`, `--accent_op`, `--accent_hov`, `--inner_text`, `--grad`, `--grad_op` и др. Не затирать их при переключении темы; при выборе пресета удалять inline-переопределения.
- **10 дополнительных stock сцен**: `retroDrive` (движущаяся SVG-машина по дороге), `neonCity`, `paintSplash`, `liquid`, `prism`, `laser`, `waves`, `orbit`, `glitch`, `petals`. Все используют `--accent`, `--grad`, `--bgc` и псевдослучайные паттерны с фиксированным seed, совпадающие между карточкой и полноценным фоном. Стоковые сцены **не занимают** шесть пользовательских слотов.
- **Скорость движения**: `BackgroundEffects.speed` в диапазоне 0.5–3, шаг 0.25, серверный `settings.bg_effects.speed`. Настройка `SeekBar` доступна только когда фон имеет анимацию и включено движение, иначе **disabled** (как при «Монохроме»). CSS `--scene-duration` ускоряется/замедляется пропорционально скорости; `prefers-reduced-motion` отключает анимацию.
- **Пользовательские фоны**: в `BackgroundLibrary` никакие названия и повторяющиеся «Изменить фон» под своими миниатюрами не показывать; выбор по превью, удаление отдельно с `notValid`. У стандартных фонов подписи по центру остаются.
- **Roadmap**: текущая dev 0.6.2, 0.5 — только «Афродита», у каждой 0.5.x есть «Улучшение интерфейса», переименованы основные вехи. 0.6.1 переносится в историю, не теряя данные.

### 2026-11-04 — объединение палитры в одну модалку

Одна кнопка «Свои цвета» теперь расположена под двумя самостоятельными пресетными пикерами.
