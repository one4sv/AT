## Ключевые инварианты продукта

1. У активности без беседы — владелец и максимум один приглашённый/принятый участник; для большего числа нужна беседа.
2. `completion_mode` определяет общие/личные отметки дня; `metric_progress_mode` — общие/личные метрики; `schedule_blocks_mode` — блоки расписания. Это **разные** настройки.
3. Беседа определяет права и разрешения участника; заблокированный не должен получать доступ через альтернативный API.
4. `owner` (владелец беседы) всегда имеет 15/15 прав, приоритет 100, роль нельзя изменить, назначить по умолчанию или вручную выдать другому пользователю.
5. Нельзя выполнить дату до вступления в беседу, включая обход через API. День вступления допустим; сравнение по календарю Москвы.
6. Во всех модалках применять общий `Blackout`, в выборе ролей — `SelectList`, текстовые поля — `TA`/`AutoDesc`. Не добавлять лишний крестик/«Отмена» в модалку «Права и роли».
7. Пользовательский стиль: 24px, `vw/dvh`, тема, многострочный SCSS, **не добавлять `font-weight`**.
8. Русская и английская локализации меняются синхронно; уникальные рисованные SVG создаются в `SectionArt`.

## Исторические указания, которые остаются полезными

- Приглашения в активности появляются в личном чате, принятый участник должен получить доступ, отказ и повторное приглашение — отдельные сценарии.
- Меню совместной активности отображает владельца и пару либо беседу; в беседе прямое приглашение третьего в активность не предлагается.
- Подтверждение требуется для исключения и удаления; обрабатывать права, приватность приглашений, блокировки и комментарии с авторами.
- Жесты SideMenu, горизонтального слайдера и сворачивания не могут выполняться одновременно.
- Реальный пользовательский пример привычки №19 **не использовать** для автоматизированного изменения данных.

### 04.11.2026 — мгновенное оформление фона без статичного кадра

- `settings_bg_effects` хранит весь `BackgroundEffects` (размытие, movement, filter, speed) через штатный `useLocalStorage`, а не `useState` с пустыми значениями.
- Ключ включён в `APPEARANCE_KEYS`: последнее оформление продублировано в `settings_appearance` и доступно до получения пользователя, как accent/grad/bg. Пользовательский ключ `<nick>_settings_bg_effects` отделяет настройки разных аккаунтов.
- Сначала рисуется значение из localStorage; запрос `settings` не должен заменять актуальный локальный кэш устаревшим ответом. Сервер используется для первичной гидратации, когда локального значения нет. `refetchSettings` не должен возвращать фон к дефолтным значениям.
- При первом входе без локального кэша `Background` не рисует промежуточный статичный кадр: ждёт завершения загрузки настроек; при последующих открытиях локальный кэш применяется уже при первом React render.
- Изменение ползунка, фильтра или переключателя мгновенно меняет `bgEffects` в контексте, перерисовывает фон и сохраняется в localStorage; отправка на сервер остаётся с debounce. Проверить reload, медленный сервер, смену аккаунта, ошибку API и 0×.

### 2026-11-04 — исправление обрезания движущихся фонов

- `Background` создаёт **неподвижную** внешнюю рамку `.background` (`overflow:hidden`) и внутренний `.backgroundCanvas` с запасом за экраном `--background-bleed`. Именно внутренний слой получает `filter`, `atBackgroundDrift` и `--scene-duration`, чтобы размытие и перемещение никогда не открывали края контейнера. Не анимировать и не фильтровать внешний clipping frame.
- Запас края зависит от `bgEffects.blur` и не требует повторного запроса API; изменения мгновенно отражаются через `useLocalStorage`. Компонент одинаков для страницы, бокового меню и полноэкранного просмотра. Отдельные SVG-сцены рендерятся внутри `.backgroundCanvas`.
- `.atScenePattern` не обрезает частицы собственным `overflow:hidden`: margin 8% для `atFloat`, margin 24% для вращения `orbit`. Границы сцены остаются в `.atScene`, поэтому фон не вылезает поверх интерфейса.
- QA: проверить движение, blur 0 и 30px, скорости 0/1/3×, все stock-фоны, изображения пользователя, полноэкранный просмотр, SideMenu, узкий viewport и уменьшение движения. Нет резких прямоугольных краёв или открытых полос на любом кадре.

### 04.11.2026 — предпросмотр фоновых сцен, паттерны, переключение движения

- В `BackgroundLibrary` выбор **не** включает `bg_effects.movement` автоматически. Движение включается/выключается только через отдельный `Toggler`; у статичных фонов он передаёт `disable={!supportsBackgroundMotion(bg)}`, визуально сереет, а `SeekBar` скорости тоже заблокирован. Никаких фоновых запросов `updatesettings` при простом выборе стандартного фона.
- Рядом с именем стандартного фона показываются компактные SVG-иконки возможностей с `title` на обёртке: `Film` — анимация доступна, `Palette` — цвета фона зависят от темы. Не ставить `title` прямо на Lucide-SVG (TypeScript не поддерживает этот prop).
- Для `color` сплошной фон **обязательно** рендерится внутренним `.backgroundCanvas` с `var(--bgc)` и эффектом `getBackgroundFilter`, иначе фильтр `invert` («Негатив») не работает.
- Контурные фигуры: `ContourPatternPicker` с двумя специально нарисованными SVG (сеткой «Порядок» и перекрывающимися фигурами «Хаос»). Настройка `settings_contour_pattern` использует `useLocalStorage`, включена в `APPEARANCE_KEYS` и доступна в `SettingsContext`. Два стабильных seeded набора в `BackIconsScene`: упорядоченный и хаотичный, пересекающийся. Превью и основной фон используют один паттерн.
- NeonCity: явно поднять `atNeonSkyline` над свечением/дорожной текстурой по `z-index`, сохранить различимость зданий и окон внизу и на высоких экранах.
- `BackgroundFullscreen`: единый `backgroundCatalog` для каталога и просмотра, стрелки на ПК, горизонтальный свайп на iPhone (как в `ImgPrev` через `framer-motion` `animate/useMotionValue`), подпись текущего фона внизу через `modulesenderInfo`, счётчик и список переключения по нажатию. В раскрываемой панели доступны фильтр, blur, movement, speed и паттерн, но **только в состоянии самого предпросмотра**. Ни `setBgEffects`, ни API `updatesettings` там вызывать нельзя; при выходе всё возвращается к сохранённым параметрам. Круглая кнопка закрытия остаётся снизу по центру в `PageBottom`.
- QA: проверить фильтр «Негатив» на сплошном фоне, неизменность movement при выборе, серый disabled toggler и slider, tooltip SVG, оба паттерна в разных темах, порядок слоёв неона, свайп/стрелки/keyboard на ПК/iPhone, список/настройки и отсутствие изменений настроек приложения после закрытия. Должны учитываться `prefers-reduced-motion`, безопасная область экрана и отсутствие двойного выбора фоновой плитки.
