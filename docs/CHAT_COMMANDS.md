# Команды и подсказки в «Избранном» (AT 0.6+)

## Этап 1 — реализованный интерфейс

В личном чате с самим собой (`/chat/:ownNick`) доступны команды `/act` и `/plan`. Кнопка `/` расположена рядом с эмодзи и скрывается при вводе обычного текста. Placeholder в «Избранном» подсказывает о командах; в остальных чатах остаётся прежний текст.

При вводе `/` открывается единый React-список `EntitySuggestionList` из `src/components/ts/EntitySuggestionList.tsx` со стилями `src/scss/entitySuggestionList.scss`. Контракт списка универсален: `items` (`id`, `label`, `description`, `icon`, `suffix`), `activeIndex`, `onSelect`, `onPreview`, `onPreviewEnd`. Позже этот же список должен принимать пользователей, планы, активности и другие сущности, не создавая отдельного списка для каждого типа. В SideMenu будущие фильтры выводятся штатным `ContextMenu`, не вторым picker.

На ПК hover визуально подставляет шаблон в существующий `TA`, но не теряет исходный введённый текст; click фиксирует шаблон и ставит каретку после первого поля. Стрелки вверх/вниз выбирают команду, Enter подставляет шаблон. После заполнения Enter или кнопка отправки **открывает** штатную модалку, но не отправляет команду как сообщение. Действие происходит только после сохранения формы.

Синтаксис: `/act название: ...; описание: ...; периодичность: каждый день; начало: 12:00; конец: 19:00` и `/plan название: ...; описание: ...; дата: 31.12.2026; начало: 12:00; конец: 13:00`. Поддерживаются альтернативные EN-имена полей. Указанные поля предзаполняют существующие `AddHabit` и `AddPlan`; необязательные поля остаются для ручного заполнения. При нераспознанном значении форма не получает неподтверждённые поля. Служебные токены отображаются с `var(--accent_highlight)` через слой текстовой подсветки поверх `TA`, не заменяя его.

`Blackout.commandDraft` хранит временные значения только для текущей модалки, передаёт их через обычные React props/state. В остальном `AddHabit`, `AddPlan`, `PlanEditor` сохраняют существующую бизнес-логику, API, модалки и валидацию. Переводы только `src/i18n/locales/{ru,en}/common.json` и `i18next`.

## После этого этапа

Упоминания пользователей, интерактивные карточки в обычных чатах, автоматическое распознавание даты/времени в естественном тексте, глобальный поиск SideMenu, правила push из заглушённых бесед — **план**, ещё не реализация. Зафиксировано: `@mention` может отправлять push в заглушённой беседе, только если включены уведомления об упоминаниях; индикатор обычных непрочитанных остаётся серым.

## Проверки

Не отправлять `/act` и `/plan` как текст. Проверить типизацию, Vite build, RU/EN, обычные чаты, сохранение модальных полей, редактирование чужих сообщений, iPhone/ПК, hover → mouseleave, Escape, Tab, клавиатуру и IME. Не считать сборку доказательством реального E2E.

Автоматическая регрессия парсера: `node --experimental-strip-types --test tests/quick-create-command.test.mjs`, выполняется также в CI клиента. При прокрутке многострочного `TA` слой подсветки синхронизируется с `textarea.scrollTop`. В момент ручного ввода команды открытая панель эмодзи закрывается.

## Этап 2 — распознавание заметок в «Избранном» (21.11.2026)

Клиентский `src/components/ts/utils/savedMessageSuggestion.ts` распознаёт:
- `31.12 12.00 врач` → разовый план с названием, датой и временем;
- `каждый день работа с 12 до 19` → ежедневная активность с периодом;
- `2 марта др кента` → план, только когда 2 марта ещё впереди в текущем году. Прошедшую дату не переносить автоматически в следующий год; для 2027 года вводить `2 марта 2027 др кента`.

Разбор работает локально, без AI или новых запросов на сервер. `Chat.tsx` выбирает только последнее подтверждённое собственное сообщение в self-chat. Старые, чужие, системные, отредактированные, пересланные сообщения и сообщения с файлами не получают подсказку. При следующем сообщении прежняя подсказка исчезает.

Сравнивать дату с `todayStrFunc()`, а часы с `clockInAppZone()` — учитывается выбранный часовой пояс AT. Ошибочные и прошедшие планы игнорировать. Кликабельная подсветка `var(--accent_highlight)` открывает стандартный `Blackout → AddHabit/AddPlan` с `commandDraft`; не создавать сущность до сохранения в модалке. После нажатия предложение для этого message ID скрывается.

В «Настройки → Чаты → Избранное» переключатель `chat_saved_suggestions` реализован через `useLocalStorage`: настройка по аккаунту и устройству, включена по умолчанию. Отключает только автоподсказки; команды `/act` и `/plan` остаются.

Покрытие: `tests/saved-message-suggestions.test.mjs` (прошедшие/будущие даты, повторяемые активности, RU/EN и ложные срабатывания), GitHub Actions и TypeScript build. Unit-тесты не подтверждают реальное сохранение через модалку.
