# AchieveTogether

AchieveTogether (AT) — веб-приложение для привычек и активностей, личного прогресса, общения и совместной работы над целями. Проект находится в активной разработке.

**Сайт:** [achievetogether.vercel.app](https://achievetogether.vercel.app/) · **Текущая метка разработки в Info:** `dev 0.6` · [Roadmap](https://achievetogether.vercel.app/info/roadmap)

## Возможности

- Активности с календарём, циклами, задачами, обычными отметками выполнения, таймером, счётчиком и статистикой.
- Совместные активности вдвоём или в беседе: приглашения, права, личное/общее выполнение, общий либо индивидуальный прогресс.
- Беседы, личные чаты, роли и разрешения участников, приглашения и QR-коды.
- Посты с форматированием текста и медиа, страницы публикаций и действия с ними.
- Персонализация: светлая и тёмная темы, акцент/градиент, декоративные режимы, русский и английский язык **в локализованных разделах**. Полный перевод всего приложения ещё не подтверждён.
- Раздел Info: о проекте, контакты, FAQ, соглашение, политика и история развития.

У продукта есть незавершённые функции и известные регрессионные сценарии; статус работающего деплоя не означает завершённый E2E. Подробности — [требования dev 0.6](docs/V0_6_FEATURES_AND_QA.md) и [тестовый чек-лист](docs/RELEASE_QA.md).

## Быстрый старт

Требуются Node.js, npm и настроенный доступ к API. Клиент основан на React/TypeScript, Vite и SCSS. В текущем репозитории нет закоммиченного lockfile, поэтому для первого локального запуска показан `npm install`, а не `npm ci`.

```bash
npm install
npm run dev
```

Для проверки:

```bash
npm run build
npm run lint
```

Сборка выполняет `tsc -b && vite build`. Клиентский API использует `/api/` и cookies; backend находится в отдельном репозитории [one4sv/achievetogether-server](https://github.com/one4sv/achievetogether-server). Перед локальным запуском изучить `vercel.json`, маршруты и конфигурацию окружения. Не публиковать секретные ключи.

## Репозиторий

- `src/pages/` — страницы, включая `/info/roadmap`, привычки, группы, посты и настройки.
- `src/components/ts/` — самописные компоненты.
- `src/components/modules/` — модалки и `ModuleMap`.
- `src/components/context/` и `hooks/` — бизнес-состояние и действия.
- `src/scss/` — темы, миксины, глобальные стили.
- `src/i18n/locales/ru` и `en` — переводимые строки.
- `docs/` — [вся документация и навигация по ней](docs/README.md).

## Правила участия в разработке

Начать с [AGENTS.md](AGENTS.md), [стиля кода](docs/CODE_STYLE.md), [каталога компонентов](docs/CUSTOM_COMPONENTS.md), [локализации](docs/I18N.md) и [рисованных SVG](docs/SVG_ART.md). Использовать существующие компоненты, цвета темы, размеры и жесты. **Не добавлять `font-weight`** при исправлениях UI. Проверять права на сервере, а не только в React.
